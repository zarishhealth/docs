# Documentation templates

Start with the template that matches the reader's goal. Remove instructional notes and placeholders before publishing a page. Templates are starting points, not required boilerplate.

| Template | Use it for |
| --- | --- |
| [Concept](concept.md) | Explain a topic, why it matters, and how it fits |
| [How-to](how-to.md) | Help a reader complete one task |
| [Reference](reference.md) | Record stable rules, fields, or formats |
| [Troubleshooting](troubleshooting.md) | Help a reader diagnose and resolve a problem |
| [Decision record](decision-record.md) | Record context, options, a decision, and its consequences |
| [Diagram brief](diagram-brief.md) | Plan and review a diagram before adding it |

For the repository-wide rules, see the [content model](../../content/reference/content-model.md) and [contributing guide](../../content/guides/contributing.md).
